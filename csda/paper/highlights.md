# Highlights

## Automated Assessment of Residual Plots with Computer Vision Models

- Computer vision model automates the residual plot lineup test
- Model predicts a Kullback-Leibler distance from a good residual plot
- More sensitive than human visual inference, less than residual tests
- Demonstrated on simulated, classical, and contemporary data examples
